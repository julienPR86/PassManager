# PassManager

## Description
This is a personal project to learn the basics about strings and file management in C.

### Dependencies

- `make`
- `gcc`

## Instruction

To compile the project:
```
make
```

To start the executable:
```
./manager
```

To remove object files:
```
make clean
```
To remove object files and executable:
```
make fclean
```
